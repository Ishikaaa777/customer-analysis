Customer Shopping Behavior Analysis

1. Overview

The Customer Shopping Behavior Analysis project is an end-to-end data analytics project focused on exploring customer purchasing patterns and identifying meaningful insights from shopping data.

The project uses Python for data exploration and preprocessing, PostgreSQL for database management and SQL analysis, and Power BI for interactive data visualization.

The main objective is to transform raw customer shopping data into structured information that helps understand purchasing behaviour, customer preferences, revenue patterns, and shopping trends.

2. Dataset

The project uses a customer shopping behavior dataset containing 3,900 customer records and 18 columns.

The dataset includes information such as:

Customer ID and Age

Gender and Location

Products Purchased and Categories

Purchase Amount

Review Ratings

Subscription Status

Shipping Type

Discount and Promo Code Usage

Previous Purchases

Payment Method

Purchase Frequency

Dataset File: Customer-shopping-behavior.csv

4. Project Steps

Step 1: Data Loading and Exploration

Imported the CSV dataset using Pandas.

Examined the dataset using head() and info().

Generated descriptive statistics using describe().

Checked missing values and reviewed data types.

Step 2: Data Cleaning and Preprocessing

Identified missing values in the Review Rating column.

Handled missing review ratings using category-wise median imputation.

Standardized column names into lowercase and replaced spaces with underscores.

Renamed the purchase amount column for easier analysis.

Created age groups using quartile-based categorization.

Converted purchase frequency categories into corresponding day values.

Removed the unnecessary Promo Code Used column from the processed dataset.

Step 3: Exploratory Data Analysis (EDA)

Explored customer demographics and purchasing information.

Examined product categories and purchasing patterns.

Analysed numerical and categorical variables.

Used descriptive statistics to understand the dataset.

Step 4: PostgreSQL Database Integration

Connected Python with PostgreSQL using SQLAlchemy and Psycopg2.

Loaded the processed DataFrame into the customer_behavior database.

Created the customer table using Pandas to_sql().

Prepared the data for SQL-based analysis.

Step 5: SQL Analysis

Performed 10 SQL analyses to explore different aspects of customer shopping behaviour:

Revenue Analysis: Compared total revenue generated by male and female customers.

Discount & Spending Analysis: Identified customers using discounts whose purchase amounts were at or above the overall average.

Product Rating Analysis: Ranked the top five products by average review rating.

Shipping Analysis: Compared average purchase amounts for Standard and Express shipping.

Subscription Analysis: Compared customer counts, average spending, and total revenue between subscribers and non-subscribers.

Discount Dependency Analysis: Identified the top five products by percentage of purchases with discounts applied.

Customer Segmentation: Classified customers into New, Returning, and Loyal segments based on previous purchases.

Product Popularity Analysis: Identified the top three most purchased products within each category.

Repeat Buyer Analysis: Compared subscription status among customers with more than five previous purchases.

Age Group Revenue Analysis: Compared total revenue across different customer age groups.

Step 6: Power BI Dashboard

Developed an interactive dashboard using Power BI.

Presented customer shopping information through visualizations.

Organized analytical information to support easier interpretation of customer purchasing behaviour.
